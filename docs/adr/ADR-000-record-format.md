# ADR-000 — Architecture Decision Record Format

Status: **Accepted / process**

## Purpose

This process record defines the minimum structure expected for Enshrouded Sleep ADRs. It is not a gameplay architecture decision.

## Required fields

Each ADR should include:

- Status
- Context
- Decision
- Alternatives considered
- Consequences / tradeoffs
- Validation evidence
- Related spike/issue/commit references when applicable

## Status values

Recommended statuses:

- Proposed
- Accepted
- Superseded
- Deprecated
- Rejected

A superseded ADR should remain in the repository and link to the replacement decision rather than being deleted.

## Numbering

ADR numbers are stable and never reused. ADR-000 is reserved for this format/process note; architectural decisions begin at ADR-001.
